# Входной контроль резьбовых втулок — ОПМ

Карта входного контроля резьбовых втулок по ОСТ 4Г 0.822.001…009: подбор изделия по обозначению (МН/СЧХ или ЮПИЯ), номинальные размеры, поля допусков, марка материала, покрытие, план выборки и лист измерений — всё в одном офлайн-инструменте (одностраничный HTML, без сервера и базы данных).

## Как открыть

### Вариант 1 — GitHub Pages (постоянная публичная ссылка)

1. Загрузите файлы этого репозитория в свой GitHub-репозиторий (веб-интерфейс: **Add file → Upload files**, либо `git push` — см. ниже).
2. В репозитории откройте **Settings → Pages**.
3. В **Source** выберите ветку `main` и папку `/ (root)`, нажмите **Save**.
4. Через 1–2 минуты страница будет доступна по адресу:
   `https://<ваш-логин>.github.io/<имя-репозитория>/`

### Вариант 2 — открыть локально

Просто откройте `index.html` в браузере — инструмент полностью самодостаточен (стили, шрифты и логика зашиты внутри файла), интернет не нужен.

## Загрузка через git (если работаете из терминала)

```bash
git init
git add index.html .nojekyll README.md
git commit -m "Карта входного контроля резьбовых втулок"
git branch -M main
git remote add origin https://github.com/<ваш-логин>/<имя-репозитория>.git
git push -u origin main
```

Файл `.nojekyll` отключает обработку Jekyll на GitHub Pages — без него ничего не сломается, но так безопаснее для одностраничных приложений.

## Подключение как Telegram Mini App

После публикации на GitHub Pages ссылку `https://<ваш-логин>.github.io/<имя-репозитория>/` можно указать в @BotFather:

`/mybots` → выбрать бота → **Bot Settings** → **Menu Button** → **Configure Menu Button** → вставить ссылку и текст кнопки.

В отличие от ссылки на артефакт, ссылка на GitHub Pages не зависит от аккаунта Claude и остаётся вашей постоянно.

## Обновление данных

Все данные (стандарты, размеры, допуски, чек-лист) зашиты в `<script>` внутри `index.html` в виде обычного JS-объекта — редактируются прямо в файле. После правки — повторно закоммитить и запушить (или заново загрузить файл через веб-интерфейс GitHub), Pages обновится автоматически.

## Источник данных

Сборник ОСТ 4Г 0.822.001…009 «Втулки резьбовые», издание 1983 г., с изменениями по извещениям 6–15. Эскизы — вырезки из сканов сборника, 300 dpi, без перерисовки.
