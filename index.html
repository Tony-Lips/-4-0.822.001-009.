Что это

Карта входного контроля резьбовых втулок по ОСТ 4Г 0.822.001…009. Справочник содержит 1130 исполнений из семи стандартов — ОСТ 002, 003, 004, 005, 006, 007 и 008. Файл автономный: работает без интернета, ничего никуда не отправляет, введённые данные нигде не сохраняются.

Выбор втулки

Три способа, работают вместе:

Фильтры
Стандарт → таблица → резьба d. Список таблиц и резьб подстраивается под выбранный стандарт.
Поиск
Понимает оба обозначения — по МН СЧХ (БА8.226.317-34) и по Классификатору ЕСКД (ЮПИЯ.713361.005-34). Дефисы и пробелы можно не набирать, достаточно куска номера: 226.317 или 713361.
Список
Нажатие на строку открывает карту.

Размеры и предельные отклонения

Номиналы берутся из таблиц стандарта, поля допусков — из его же граф. Предельные отклонения и граничные значения рассчитываются по таблице IT.

Важно. Все размеры даны до нанесения покрытия. Резьба после покрытия контролируется предельными калибрами ПР/НЕ по номинальному профилю (п. 1.5 и 3.5 ОСТ 4Г 0.822.009).

Прочерк в графе отклонений означает, что размер не контролируется расчётом:

План выборки

Введите объём партии N — программа выдаст объём выборки n, приёмочное Ac и браковочное Re число по ГОСТ 17769-83:

до 50n = 5, Ac = 0, Re = 1 — рекомендуется сплошной контроль
51…500n = 13, Ac = 0, Re = 1
501…3200n = 32, Ac = 1, Re = 2
свыше 3200n = 50, Ac = 2, Re = 3

Для специзготовления по чертежам и мелкосерийных опытно-промышленных партий — сплошной контроль вместо выборочного.

Замеры образцов

Сетка появляется, когда выбрана втулка и введён объём партии. Строки — образцы, столбцы — параметры. Вводите фактические размеры в миллиметрах, разделитель — запятая или точка.

Подсветка
Зелёная — значение в поле допуска, красная — вышло за предельные отклонения. Неконтролируемые графы подсветку не получают.
Итог по строке
Образец считается забракованным, если хотя бы один его размер вне допуска.
Решение по выборке
Сравнивается число забракованных образцов с приёмочным числом Ac.
Число образцов
По умолчанию — по плану. Кнопки «+ Добавить» и «− Убрать последний» меняют количество, крестик в строке удаляет конкретный образец со сдвигом остальных вверх. Отклонение от плана подсвечивается красной плашкой и указывается в заключении — скрыть его нельзя. «Вернуть по ГОСТ» восстанавливает плановое число.

Разделы по галочкам

Появляются после выбора втулки, по умолчанию выключены:

Чек-лист
Достраивает в таблицу «Размеры» колонки с замерами по образцам и итог по строке. Колонки предельных отклонений видны всегда, независимо от галочки.
Контрольные операции
Десять операций из раздела 3 ОСТ 4Г 0.822.009 с указанием пунктов и методов.
Заключение
Сводка: партия, объём, выборка, число забракованных, решение, реквизиты ОТК. Заполняется из блока «Реквизиты партии» на вкладке «План выборки».

Печать

Кнопка «Печать» в шапке готовит карту на бумагу: фильтры, вкладки и кнопки удаления скрываются, разделы не разрываются между страницами.

Источник данных

Сборник ОСТ 4Г 0.822.001…009 «Втулки резьбовые», издание 1983 г., с изменениями по извещениям 6–15. Данные набраны по сканам, эскизы — вырезки из тех же сканов в исходном растре 300 dpi, без перерисовки. Марки материалов и покрытия приведены в действующей редакции: сталь АС14 вместо А12, ГОСТ 9.306-85 вместо 9.073-77, поле допуска d3 — H12 по извещению 13.

Значения Ac и Re перед утверждением карты сверьте с действующей редакцией ГОСТ 17769-83. Для ввёртываемых втулок отклонения d2 и D2 заданы в стандарте числами и в расчёт пока не заведены.
